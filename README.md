# Võ Lâm — Thế Giới Mở 2.5D

Game nhập vai kiếm hiệp thế giới mở chơi trực tiếp trên trình duyệt (máy tính & điện thoại).

**Chơi ngay:** mở link GitHub Pages của repo này.

- 120 nhân vật kiếm hiệp, 12 môn phái với tổng đàn riêng
- Võ học sâu: liên chiêu/hợp kích, tâm pháp, ngộ biến chiêu
- Thế giới mở rộng lớn, boss dã ngoại, sự kiện giang hồ, tình duyên & gia tộc

Save game lưu trong trình duyệt của người chơi.
